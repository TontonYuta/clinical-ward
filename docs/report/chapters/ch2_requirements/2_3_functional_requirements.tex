\section{Danh mục yêu cầu chức năng (Functional Requirements)}
\label{sec:functional_requirements}

\subsection{Cấu trúc phân rã chức năng hệ thống (Functional Decomposition)}
\label{subsec:functional_decomposition}

Nhằm đáp ứng toàn diện các nghiệp vụ lâm sàng và quản trị vận hành, hệ thống Clinical Ward CDSS được phân rã thành bốn phân hệ chức năng chính:

\begin{enumerate}[leftmargin=1.8em]
    \item \textbf{Phân hệ 1: Kê đơn CPOE và Cảnh báo an toàn lâm sàng CDSS (Core CDSS):} Bao gồm các chức năng tạo đơn, quét ma trận tương tác $O(1)$, phát hiện hội chứng đa thuốc, ước tính $eGFR$ và kiểm soát trần liều 24 giờ.
    \item \textbf{Phân hệ 2: Trợ lý Dược lâm sàng RAG và Đối soát y văn (Clinical RAG):} Cung cấp khả năng hỏi đáp y văn trong ranh giới ngữ cảnh đóng, phân tích bằng chứng số trang và kiểm định chống ảo giác định lượng.
    \item \textbf{Phân hệ 3: Quản trị Kho dược và Hỗ trợ điều dưỡng buồng bệnh (Ward Logistics):} Bao gồm quét nhận diện thẻ BHYT qua thị giác máy tính, xuất kho ưu tiên hạn dùng FEFO và quản lý khép kín vỏ thuốc gây nghiện.
    \item \textbf{Phân hệ 4: Quản trị hệ thống, Giám sát AI và Bảo mật dữ liệu (Admin \& Security):} Đảm nhiệm xác thực phân quyền Argon2id, quản lý nhân viên CSDL, đồng bộ dữ liệu đám mây đa thiết bị, giám sát lưu lượng token Telemetry và quản lý kho khóa API dự phòng.
\end{enumerate}
